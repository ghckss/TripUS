# Field Notes 원본 에셋

출처: TripUS · 세 가지 디자인 방향 / 여행의 여백 · Field Notes
https://www.figma.com/design/GmAwOgyaeo6s44x0pDcJbU?node-id=0-1

Chrome의 Figma Export 기능으로 받은 SVG에서 해당 원본 그룹만 분리하고 투명 여백을 제거해 PNG로 렌더링했다. 도형·색상·비율은 원본을 유지한다.

- journey.png: Group_16 (여행 허브 일러스트)
- cafe.png: Group_32 (카페)
- park.png: Group_34 (산책)
- home.png / bookmark.png / route.png / journal.png: Group_23~26 (하단 탐색 아이콘)

일러스트는 여행의 장식 이미지이며 실제 장소 사진·지도·방문 데이터는 API에서 받은 값을 사용한다.
