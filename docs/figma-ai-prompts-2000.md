# Figma AI용 2,000자 이하 프롬프트

각 코드 블록을 한 번에 하나씩 입력한다. 먼저 1번으로 전체 구조를 만든 뒤 2~4번을 순서대로 사용해 화면을 확장한다.

## 1. 최초 생성 프롬프트

```text
모바일 여행 플래닝·기록 앱 ‘TripUS’를 390x844px 기준으로 디자인해 주세요. 따뜻한 여행 노트 감성과 지도·일정을 빠르게 읽는 명확한 UI를 결합하세요. 코랄/오렌지를 주조색, 딥블루를 보조색으로 사용하고 접근 가능한 명도 대비를 지켜주세요.

사용자가 장소를 저장하면 AI가 날짜별로 묶고 방문 순서를 제안합니다. 사용자는 장소를 날짜 안팎으로 드래그하고 추가·삭제·반복 배치하거나 잠글 수 있습니다. 제거한 장소는 ‘미배치 장소’에 남깁니다. 분 단위 일정표나 내비게이션이 아니며, 대중교통 기준 예상 이동시간과 경로를 보여주고 실제 길 찾기는 Google Maps로 연결합니다.

일관된 디자인 시스템으로 다음 화면을 만드세요: 온보딩/로그인, 내 여행, 여행 생성, 여행 상세, 장소 검색·저장, 저장 장소·미배치 보관함, 숙소·날짜 설정, AI 일정 만들기와 결과, 일정 편집, 오늘 일정, 다녀온 여행, 기록 상세·지도 다시보기.

여행 상세은 장소·일정·지도·기록의 관계가 명확해야 합니다. 일정에는 날짜별 장소 카드, 순서, 장소 사이 이동시간, 잠금과 충돌 경고를 표시하세요. AI 결과에는 ‘AI 추천’과 미배치 이유를 표시하고, 추천 추가 전 ‘2일 차에 추가 · 총 이동시간 +18분’처럼 시간 증감을 강조하세요.

여행 후 일정은 하나의 최종 기록이 됩니다. 방문 상태는 평가 완료·미평가·미방문이며 반복 방문마다 사진·점수·후기를 가집니다. 다시보기에는 날짜별 순서와 움직이는 마커를 보여주고 ‘방문 순서를 기반으로 재구성한 여정’이라고 안내하세요. SNS·업무 캘린더·실시간 위치 추적 UI는 제외하세요.
```

## 2. AI 계획 및 편집 화면 확장

```text
TripUS의 AI 계획 흐름을 확장해 주세요. ‘일정 만들기’를 누르면 여행 스타일을 카드로 질문합니다: 관광·맛집·쇼핑 골고루, 맛집·카페·야시장 중심, 유명 관광지 최대한 많이, 여유로운 일정·휴식 중심. 저장 장소가 부족한 촘촘한 일정에는 AI가 장소를 추가하며 반드시 ‘AI 추천’ 배지와 이유, Google 평점을 표시합니다.

생성 결과는 날짜별 세로 타임라인으로 만들고 장소 순서, 대중교통 예상 이동시간, 숙소 출발·종료, 미배치 장소와 이유를 보여주세요. 같은 날짜 및 날짜 사이 드래그, 반복 배치, 잠금, 삭제 시 미배치 보관함 복귀를 지원하세요. ‘이 날짜만 다시 짜기’, ‘전체 일정 다시 짜기’를 제공하고 변경 전후 비교 화면에는 이동·추가·제거 장소와 총 이동시간 증감을 표시하세요. 적용, 취소, 적용 직후 한 번 되돌리기를 제공하되 버전 히스토리는 만들지 마세요.

운영시간이나 하루 종료시간 충돌은 저장을 막지 말고 인라인 경고로 표시하세요. 로딩, AI 실패, 대중교통 경로 없음, 폐업·이전 장소, 빈 미배치 보관함 상태도 디자인하세요. 일정과 경로는 예상 정보이며 방문 전 최신 정보를 확인해야 한다는 안내를 포함하세요.
```

## 3. 여행 완료 및 기록 화면 확장

```text
TripUS의 여행 완료·기록 흐름을 확장해 주세요. 여행 종료 후 날짜별 일정 장소에 평가 완료·미평가·미방문 상태를 선택하고, 계획에 없던 방문 장소를 추가할 수 있게 하세요. 정리 없이 보관하면 일정 장소가 미평가 방문으로 처리된다는 확인 문구를 보여주세요.

방문 기록 화면에는 장소, 방문 날짜·시간, 만족도 점수, 후기, 여러 사진, 대표 사진을 배치하세요. 같은 장소의 반복 방문은 각각 독립적인 사진·점수·후기를 가집니다. 사진 자동 분류 후보, 업로드 진행률, 실패 재시도, 오프라인 임시 저장 상태도 디자인하세요.

다녀온 여행 목록에는 대표 사진, 여행지·기간, 방문 장소 수, 평가 장소 수, 해당 지역 방문 횟수를 표시하세요. 기록 상세에는 대표 사진 중심 헤더, 날짜별 타임라인, 장소별 사진·후기, 총 이동 거리와 방문 장소 수, 지도 애니메이션을 넣으세요. 미방문 장소는 다시보기에서 제외하며 실제 GPS 경로가 아니라는 안내를 명확히 표시하세요. 계획/기록 전환 토글은 만들지 말고 최종 데이터 하나만 보여주세요.
```

## 4. 권한·요금제·예외 상태 확장

```text
TripUS의 권한, 요금제와 예외 상태를 확장해 주세요. 만든 사람만 편집하고 초대받은 사용자는 읽기만 가능하므로 소유자·읽기 전용 배지와 비활성 편집 UI를 만드세요. 진행 중인 여행은 비공개이며 외부 공개 링크나 SNS 공유 UI는 넣지 마세요.

무료 사용자는 활성·보관 합계 여행 1개와 계정 전체 AI 생성 1회를 사용할 수 있습니다. AI 실행 전 무료 1회 사용 확인, 이미 사용한 뒤 재생성 시 Plus 안내, 두 번째 여행 생성 시 기존 여행 삭제 또는 Plus 선택, 사진 저장 한도 도달 화면을 디자인하세요. 사용자의 원본 사진 다운로드와 삭제는 결제로 막지 마세요.

오프라인 배너와 일정 텍스트 열람, 네트워크 오류, 지도 로딩 실패, 검색 결과 없음, AI 실패 시 횟수 미차감, 사진 업로드 실패·재시도, 삭제 확인을 포함하세요. 삭제 확인에는 여행명, 복구 불가, 사진·후기 동시 삭제를 명확히 표시하세요. 모든 상태에서 친절하지만 모호하지 않은 한국어 UX 문구를 사용하세요.
```
