# TripUS Figma AI 디자인 요청서

## 1. 복사해서 사용할 핵심 프롬프트

아래 내용을 Figma AI에 우선 전달한다.

---

국내·해외 자유여행자를 위한 모바일 중심 여행 플래닝 및 여행 기록 앱 `TripUS`의 UX/UI를 디자인해 주세요.

TripUS의 핵심 경험은 사용자가 가고 싶은 장소를 먼저 저장하면 AI가 장소를 날짜별로 배치하고 방문 순서를 제안하며, 여행 후에는 동일한 일정에 사진, 만족도 점수와 후기를 더해 하나의 여행 기록으로 완성하는 것입니다.

이 앱은 분 단위 일정표나 실시간 내비게이션 앱이 아닙니다. 날짜별로 어디를 어떤 흐름으로 방문할지 보여주는 관리 앱입니다. 앱 내부 지도는 일정 경로와 움직이는 마커를 보여주는 시각화 용도이고, 실제 길 찾기는 Google Maps로 연결합니다. 이동시간과 지도 경로는 대중교통 기준입니다.

모바일 화면은 390x844px을 기준으로 디자인하고, Android와 iOS 모두에 자연스러운 반응형 구조를 사용해 주세요. 여행 감성이 느껴지는 따뜻한 디자인과 지도·일정 정보를 빠르게 읽을 수 있는 명확한 정보 구조를 결합해 주세요. 과도하게 장식적이거나 SNS 피드처럼 만들지 말아 주세요.

핵심 화면 전체를 하나의 일관된 디자인 시스템으로 만들어 주세요.

1. 로그인 및 온보딩
2. 내 여행 홈
3. 새 여행 생성
4. 여행 상세 대시보드
5. 저장 장소 목록과 미배치 장소 보관함
6. 지도 기반 장소 검색 및 장소 저장
7. 장소 상세와 유사 장소 추천
8. 숙소 및 날짜별 시작·종료 시간 설정
9. AI 일정 만들기 질문 화면
10. AI 일정 생성 중 화면
11. AI 생성 결과와 미배치 이유
12. 날짜별 일정 편집
13. AI 변경안 비교
14. 오늘 일정 확인
15. Google Maps 길 찾기 연결 UI
16. 여행 완료 및 기록 정리
17. 장소 방문별 사진·점수·후기 작성
18. 다녀온 여행 목록
19. 여행 기록 상세와 지도 다시보기
20. 읽기 전용 여행 초대 화면
21. 무료 제한 및 Plus 결제 유도
22. 오프라인, 오류, 빈 화면과 삭제 확인 상태

여행 상세에서는 `장소`, `일정`, `지도`, `기록`의 관계가 명확해야 합니다. 사용자는 저장한 장소를 일정에 여러 번 넣을 수 있고, 일정에서 제거해도 저장 장소는 미배치 보관함에 남아야 합니다.

AI 일정은 확정안이 아니라 편집 가능한 제안입니다. 같은 날짜 안에서 드래그해 순서를 바꾸고 다른 날짜로 장소를 옮길 수 있게 해 주세요. AI가 이동하면 안 되는 장소에는 잠금 기능이 필요합니다. `이 날짜만 다시 짜기`, `전체 일정 다시 짜기`, 변경 전후 비교 기능을 제공해 주세요.

추천 장소를 일정에 추가할 때는 긴 설명보다 `2일 차에 추가 · 총 이동시간 +18분`처럼 적용 전후 총 이동시간 증감값을 명확하게 보여 주세요.

여행 완료 후 방문 상태는 `평가 완료`, `미평가`, `미방문` 세 가지입니다. 정리하지 않고 보관하면 일정에 있던 장소는 모두 미평가 방문으로 처리됩니다. 미방문 장소는 최종 지도 다시보기에서 제외합니다.

지도 다시보기에는 날짜별 마커와 방문 순서가 나타나고, 경로를 따라 하나의 마커가 움직이는 경험을 보여 주세요. 이 경로가 실제 GPS 기록이 아니라 방문 순서를 바탕으로 재구성한 것임을 안내해 주세요.

진행 중인 여행은 비공개입니다. 초기 버전에는 외부 공개 링크나 SNS 공유가 없습니다. 초대받은 사용자는 읽기만 가능하고 만든 사람만 편집할 수 있습니다.

각 주요 화면에 기본 상태뿐 아니라 로딩, 빈 상태, 네트워크 오류, 대중교통 경로 없음, 폐업·이전 장소, AI 실패, 사진 업로드 실패, 무료 한도 도달 상태도 함께 디자인해 주세요.

## 2. 디자인 목표

### 사용자에게 느껴져야 하는 가치

- 장소만 모아도 여행의 윤곽이 만들어진다.
- AI가 만들었지만 내가 완전히 통제할 수 있다.
- 이동 흐름을 지도에서 직관적으로 이해할 수 있다.
- 여행이 끝나면 계획이 자연스럽게 기록으로 바뀐다.
- 다시보기가 사진과 지도 애니메이션 덕분에 매력적이다.

### 피해야 할 인상

- 분 단위 캘린더 또는 업무용 일정 관리 도구
- 실시간 위치 추적 앱
- 자동차 내비게이션 앱
- 공개 게시물 중심 SNS
- 지나치게 많은 설정을 요구하는 전문가용 여행 도구

## 3. 제안 디자인 방향

브랜드 스타일은 아직 확정되지 않았으므로 아래 방향은 디자인 초안용 제안이다.

- 분위기: 따뜻함, 기대감, 발견, 정돈된 여행 노트
- 주조색 후보: 선명한 코랄 또는 오렌지
- 보조색 후보: 지도와 신뢰 정보를 위한 인디고 또는 딥블루
- 배경: 따뜻한 화이트와 옅은 스톤 계열
- 지도 위 마커: 날짜별 색상 또는 하나의 브랜드 색상과 순서 번호
- 카드: 둥근 모서리, 낮은 그림자, 사진 비중이 높은 장소 카드
- 타이포그래피: 한국어 가독성이 좋은 산세리프
- 아이콘: 단순하고 일관된 라인 아이콘

접근성을 위해 텍스트와 배경 대비를 충분히 확보하고, 색상만으로 방문 상태나 경고를 구분하지 않는다.

## 4. 정보 구조 제안

### 전역

- 내 여행
- 다녀온 여행
- 프로필 및 요금제

### 여행 상세

- 개요
- 저장 장소
- 일정
- 지도
- 여행 기록

여행 전에는 저장 장소와 일정이 중심이고, 여행 종료 후에는 기록과 다시보기가 중심이 되도록 같은 구조 안에서 강조점이 자연스럽게 변해야 한다.

## 5. 화면별 상세 요청

### 5.1 로그인 및 온보딩

목표: 앱의 핵심 가치를 세 장 이내로 이해시킨다.

- 장소 저장
- AI 날짜별 배치
- 사진과 지도로 여행 기록 완성

위치 추적 앱처럼 보이는 문구를 사용하지 않는다.

### 5.2 내 여행 홈

- 활성 여행 카드
- 보관 여행 진입
- 새 여행 만들기
- 무료 사용자의 총 1개 여행 제한 상태
- 여행 종료 후 기록 정리 알림
- 여행이 없을 때 빈 상태

여행 카드에는 여행지, 날짜, D-Day 또는 완료 상태, 대표 이미지와 장소 수를 표시한다.

### 5.3 새 여행 생성

- 여행명
- 여행지 검색
- 시작일과 종료일
- 날짜가 미정이어도 임시 날짜를 입력해야 한다는 안내
- 여행지 시간대 자동 설정
- 첫날 출발지와 마지막 날 종료지 선택은 선택 사항

### 5.4 여행 상세 대시보드

- 여행지와 날짜
- 저장 장소 수
- 일정에 배치된 장소 수
- 미배치 장소 수
- 숙소 설정 상태
- AI 일정 만들기 CTA
- 날짜별 요약
- 지도 미리보기

AI 일정이 없는 상태와 생성된 상태를 각각 디자인한다.

### 5.5 저장 장소와 미배치 보관함

- 태그 필터: 관광, 맛집, 카페, 쇼핑, 숙소, 교통, 체험, 기타
- 방문 전 선호도
- 일정 배치 여부
- 같은 장소가 여러 번 일정에 들어간 횟수
- 미배치 이유
- 날짜에 직접 추가

일정에 배치됐더라도 저장 장소 원본이 사라지지 않는 구조를 시각적으로 이해할 수 있어야 한다.

### 5.6 장소 검색 및 저장

- 검색어 입력
- 자동완성
- 지도에서 선택
- Google Maps 링크 붙여넣기
- 중복 장소 안내
- 태그와 방문 전 선호도 선택
- 저장 완료 피드백

### 5.7 장소 상세 및 추천

- 장소명, 사진, 주소
- Google 평점과 평가 수
- 운영시간
- 운영정보 변경 가능성 안내
- 저장 및 일정에 추가
- 비슷한 장소
- 함께 가기 좋은 장소
- 가장 적합한 날짜와 총 이동시간 증감

### 5.8 숙소 및 날짜 설정

- 날짜별 시작 시간과 종료 시간
- 기본값 09:00~24:00
- 숙소 숙박 기간
- 자동 계산된 날짜별 출발지와 종료지
- 첫날 출발지와 마지막 날 종료지
- 숙소가 없는 상태

### 5.9 AI 일정 만들기

여행 스타일을 단일 선택 또는 명확한 카드 선택으로 묻는다.

- 관광·맛집·쇼핑을 골고루
- 맛집·카페·야시장 중심
- 유명 관광지를 최대한 많이
- 여유로운 일정과 휴식 중심

저장 장소, 숙소와 날짜 설정을 확인하는 요약을 함께 보여준다. 무료 AI 생성 1회를 사용한다는 사실을 실행 전에 명확히 안내한다.

### 5.10 AI 생성 중

- 날짜별 장소 구성 중
- 대중교통 흐름 확인 중
- 운영시간 확인 중
- 숙소 기준 경로 구성 중

정확한 시간을 보장하는 표현은 사용하지 않는다.

### 5.11 AI 생성 결과

- 날짜별 세로 타임라인
- 장소 순서 번호
- 장소 사이 예상 대중교통 이동시간
- AI 추천으로 추가된 장소 표시
- 미배치 장소 보관함
- 미배치 이유
- 직접 편집
- 전체 적용
- 다시 생성

화면 상단 또는 결과 하단에 예상 정보 안내 문구를 배치한다.

### 5.12 일정 편집

- 같은 날짜 안에서 드래그 앤 드롭
- 다른 날짜로 이동
- 장소 삭제 시 저장 장소 보관함으로 돌아감
- 동일 장소 반복 추가
- 날짜 또는 순서 잠금
- 충돌 경고
- 이 날짜만 다시 짜기
- 전체 일정 다시 짜기

충돌이 있어도 저장할 수 있어야 하며, 경고는 차단 모달이 아니라 인라인 경고를 우선한다.

### 5.13 AI 변경안 비교

- 변경 전과 변경 후 날짜별 비교
- 이동된 장소
- 추가·제거된 장소
- 총 이동시간 증감
- 적용
- 취소
- 적용 직후 한 번 되돌리기

버전 히스토리 화면은 만들지 않는다.

### 5.14 오늘 일정

- 오늘 날짜와 현지 요일
- 장소 순서
- 다음 장소
- 예상 대중교통 이동시간
- Google Maps에서 길 찾기
- 현장에서 발견한 장소 추가
- 사용자가 요청하는 이후 동선 재계산

방문 완료 체크박스, 실시간 위치 또는 자동 도착 UI는 넣지 않는다.

### 5.15 여행 완료 및 기록 정리

- 날짜별 계획 장소
- 평가 완료, 미평가, 미방문 선택
- 만족도 점수
- 계획에 없던 방문 장소 추가
- 사진과 후기 작성
- 정리 없이 보관

`정리 없이 보관`을 선택하면 일정 장소가 미평가 방문으로 처리된다는 설명을 확인시킨다.

### 5.16 방문 기록 작성

- 장소와 방문 날짜·시간
- 만족도 점수
- 후기
- 사진 여러 장
- 대표 사진
- 사진 자동 분류 제안
- 사진 업로드 진행률과 실패 재시도
- 네트워크 오류 시 기기 임시 저장 안내

같은 장소의 반복 방문을 각각 독립적으로 편집할 수 있어야 한다.

### 5.17 다녀온 여행 목록

- 대표 사진
- 여행지와 기간
- 방문 장소 수
- 평가 장소 수
- 해당 지역 방문 횟수
- 마지막 방문일
- 여행 상세 진입

### 5.18 여행 기록 상세 및 다시보기

- 대표 사진 중심의 헤더
- 날짜별 타임라인
- 장소별 사진과 후기
- 만족도
- 총 이동 거리와 방문 장소 수
- 지도 위 날짜별 순서 마커
- 경로를 따라 움직이는 마커
- 실제 GPS 경로가 아니라는 안내

계획 화면과 기록 화면을 별도 버전으로 전환하는 토글은 만들지 않는다. 최종 여행 데이터 하나를 보여준다.

### 5.19 읽기 전용 초대

- 초대 링크 또는 사용자 초대
- 초대 상태
- 소유자 표시
- 초대받은 사용자에게 읽기 전용 배지
- 편집 기능 비활성화

### 5.20 무료 제한과 결제 유도

무료 정책:

- 활성·보관 합계 여행 1개
- 계정 전체 AI 생성 1회

필요 상태:

- 무료 AI 생성 실행 전 확인
- AI 1회를 이미 사용한 상태

## 8. UX 문구

### 일정과 경로

> TripUS의 일정, 이동시간과 경로는 여행 계획을 돕기 위한 예상 정보입니다. 실제 교통 상황과 현지 사정에 따라 달라질 수 있습니다.

### 운영시간

> 운영시간과 휴무일은 변경될 수 있으니 방문 전 최신 정보를 확인해 주세요.

### 다시보기

> 방문 순서를 기반으로 재구성한 여정입니다. 실제 GPS 이동 경로와 다를 수 있습니다.

### 사진

> 사진 분류를 위해 기기에서 촬영일시와 위치를 일시적으로 확인할 수 있습니다. 해당 정보는 업로드 전에 제거되며 서버에 저장되지 않습니다.

### 기록 없이 보관

> 별도로 정리하지 않은 장소는 방문했지만 평가하지 않은 장소로 보관됩니다.

### 삭제

> 여행을 삭제하면 복구할 수 없으며 사진과 기록도 함께 삭제됩니다.

## 9. 프로토타입 요청

다음 핵심 흐름은 클릭 가능한 프로토타입으로 연결한다.

### 흐름 A: 첫 여행 계획

온보딩 → 여행 생성 → 장소 세 개 저장 → 숙소 등록 → AI 스타일 선택 → AI 일정 생성 → 미배치 장소 확인 → 날짜별 일정 편집 → Google Maps 길 찾기

### 흐름 B: AI 변경

일정 상세 → 장소 고정 → 이 날짜만 다시 짜기 → 변경 전후 비교 → 적용 → 한 번 되돌리기

### 흐름 C: 여행 기록

여행 종료 안내 → 기록 정리 → 장소 점수 입력 → 미방문 지정 → 추가 방문 등록 → 사진과 후기 작성 → 여행 보관 → 지도 다시보기

### 흐름 D: 무료 제한

무료 AI 1회 사용 → 재생성 선택 → Plus 안내 → 보관 여행이 있는 상태에서 새 여행 생성 → 기존 여행 삭제 또는 Plus 선택

### 흐름 E: 읽기 전용 초대

소유자의 초대 → 초대받은 사용자 열람 → 편집 불가 상태 → Google Maps 길 찾기
